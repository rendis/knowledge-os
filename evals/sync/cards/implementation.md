# AGT implementation correction card

Read the repository instructions, the frozen evaluation criteria, the exact
ledger finding, and the affected public contract. Change only the assigned
module. Do not edit tests to accommodate runtime behavior, add compatibility,
commit, tag, update a consumer, or use a graph index.

Reproduce the finding first. Implement the smallest complete correction, run
the narrow public test, then the required distribution suites. Return role,
agent id, model, effort, fork turns, input/output digests, changed files,
observed commands, and remaining risk. Stop when the assigned finding is fixed
or a concrete contract conflict is proven.
