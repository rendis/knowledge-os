# Verify the visual

Select the relevant gates before generation. Mark each pass, fail or unverified with evidence; do not silently omit an applicable gate.

| Widget | Required acceptance criteria |
|---|---|
| Flow, architecture, state machine | All required nodes and arrows present; arrowheads visible, correct direction and endpoints; transition conditions and exceptions labeled; no unsupported connection |
| Spatial explorer | Above, plus route edges agree with ordered steps, stable geometry, meaningful inspector, node-neighborhood focus and route focus, attenuated unrelated context, mutually consistent selection state, keyboard activation and full reset |
| Quantitative chart | Source rows, units, axes, denominator, period and aggregation; geometry agrees with values; missing data explicit |
| Timeline or other temporal content | Source-backed dates, visible period/as-of date and timezone when relevant; chronological order and interval spacing justified; distinguish event date from generation date; unknown dates stay unknown |
| Quadrant or comparison | Named axes/criteria, consistent comparison, measured versus qualitative positions explicit |
| Scenario calculator | Declared formula and assumptions; independent expected results, boundaries, invalid inputs and reset |

Bind `<cli>` through [use-vault-cli](../../use-vault-cli/SKILL.md). For SVG or HTML containing SVG, run `<cli> check visual "<artifact>" --kind diagram`. For spatial explorers use `--kind spatial`; annotate interactive nodes with `data-node`, edges with `data-from`/`data-to`, and edge labels with `data-edge`. Add `--temporal` when the subject requires dates, using source-backed `time[datetime]` or `data-as-of` ISO values. Never fabricate a date to pass a check. The checker catches missing identifiers, endpoints, linked labels, accessibility references, selection metadata and malformed/missing temporal dates. It does **not** prove semantic truth, visible dates or interactive behavior. Other formats need renderer-specific checks rather than an artificial SVG wrapper.

For untransformed rectangular spatial nodes and absolute M/L/C edge paths, the checker also checks that path endpoints touch their declared node bounds. Unsupported geometry fails this automatic gate and needs explicit manual evidence, not a silent pass. This still does not prove arrowhead visibility, freedom from crossings, or semantic correctness; inspect the render.

1. **Fidelity:** compare all nodes, edges, values, claims and simplifications with the brief. For spatial explorers, check each edge's actual endpoints against the named source/destination and ordered route text; a valid edge ID alone does not prove a correct connection. Recompute quantitative results from source rows. Verify that proposals and hypotheses stay labeled and no source limitation disappears through visual simplification.
2. **Render:** open every HTML/SVG in a browser at a desktop width (about 1440px) and narrow width (about 390px). Capture and inspect screenshots. Check clipped text, overlaps, edge routing, contrast, reading order, page overflow and actual label size. For SVG, check rendered font size after the viewBox scale (for example font size times `getScreenCTM()` scale); a 14px source label can shrink below the minimum on screen. Intended diagram scrolling is acceptable when labeled and accompanied by a readable alternative. Render Mermaid with an available compatible renderer and inspect it; source inspection alone is not a rendered pass.
3. **Interact:** exercise every control and reachable state, including reset, boundary inputs, keyboard focus and activation. For spatial explorers, select a node with incoming/outgoing edges, a disconnected node when present, and a route; verify the exact active node/edge/label sets, unrelated-context attenuation, route-to-node and node-to-route replacement, and All/Reset clearing all stale focus and inspector state. Compare at least two calculated outputs with independent arithmetic. Check browser errors and accidental network dependencies; verify offline operation for self-contained output. Test reduced motion when animation exists.
4. **Icons when used:** verify the icon matches a source-supported role, retains a visible name, resolves locally, fits its node without text overlap, follows selection and theme state, and includes the applicable license notice. A database or lock icon must not introduce an unsupported implementation/security claim.
5. **Retain:** check relative links, source provenance, shareability of the entire file and selected retention mode. For retained visuals, run `<cli> check visual-context "<context.md>"` on the accompanying Markdown and verify that its purpose, represented content, controls, sources and limits match this exact revision. Review both files on every update; hashes establish byte correspondence, not semantic agreement. A PNG preview does not replace editable source or quantitative data.

Return a compact receipt listing artifact, tested sizes/states, outcome and concrete remaining limits. Record screenshot paths when available. Source-only checks must be labeled unverified for visual behavior. Repair observed defects and rerun the affected checks. The human's aesthetic approval remains separate from these technical checks.

## Rendered text containment gate

For text inside cards or diagram nodes, apply the annotations from `visual-language.md` and load `scripts/check_text_fit.cjs` in an already permitted browser validation context. Call `await checkTextFit(document)` after rendering; it waits for fonts, measures actual SVG glyph bounds or HTML text ranges, and checks them against container bounds with padding. The helper does not navigate, open a browser or authorize any bypass. If the available browser tool cannot run it, inspect the same bounds manually and report that evidence separately.

Run the gate for desktop and narrow layouts and after every state that changes labels. Treat `errors` as failures and `unverified` as remaining manual work. Hidden responsive variants are checked when they become active. Rotated/skewed geometry requires manual inspection. Check all label annotations, internal label-to-label overlaps, readable scaled font sizes and font fallback visually as well; containment alone proves none of those. Repair wrapping or container geometry, then repeat the affected gate. Node-only tests of supplied rectangles are regression evidence for the helper, never proof of a rendered artifact.
