# Associated investigation evidence

Use while mapping or refreshing a repository/change with associated investigations, or absorbing selected case knowledge. This supplies evidence to the existing documentation workflow, not another writer or a full-remap requirement.

1. Use `graph-query.py investigations --node <stem>` and bounded public-case searches for repository remote, work-item or change identity. Inspect supplied case IDs directly. A repository match is only a lead: confirm overlap in component, revision and claim. An absent node link does not prove that no case exists.
2. Load relevant cases through `manage-investigation`'s helper to discover public and optional private context; preserve provenance/disclosure limits. Retired IDs resolve through the retirement record, not an invented live path. Do not restore or modify cases to read them.
3. Select useful reasons, agreements, restrictions/exceptions, supplied documents/correspondence, deployment/observation evidence and limits. Inspect their sources directly and match revision, environment, date and scope. An approval establishes an agreement, not execution. Case narrative is not proof of production behavior.
4. Apply `evidence-sufficiency.md` and the cell profile claim by claim. Incorporate supported material not derivable from code, labeling its evidence type. Changed source follows normal delta mapping; external-only evidence can enrich an unchanged-source note through the existing external reconciliation path. Preserve source-analysis metadata unless the source was re-analyzed.
5. Update canonical notes with the bounded delta and durable shareable provenance. Route lessons to their learning owner. Private correspondence requires permission before sharing. A destination must not depend solely on an ignored run, private overlay or live case that may be retired.
6. Independently review complete resulting notes under `final-note-review.md` **before publishing them**. If the reviewer is unavailable or delegation is prohibited, keep candidates staged and canonical notes unchanged; report the review blocker. A self-review receipt or structural check cannot substitute for that gate. Return only verified published destinations (or explicitly pending candidates), evidence boundaries and checks to the investigation owner; do not mutate, close or retire its case. No matching case is valid and does not block independently supported mapping.
