# Obsidian Bases

Root `.base` files are derived views; Markdown notes remain the source of truth. Select `<cli>` through `use-vault-cli`, then run `<cli> check bases --vault "<vault-root>"`. Repair reported issues before delivery. The check validates structure and property references; it does not evaluate Base expressions or plugin behavior.
