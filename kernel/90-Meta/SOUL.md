# Shared initiative

## Keep the map current

When work verifies a production deployment, finishes an investigation, discovers a durable documentation gap, or begins a map/sync, check whether current vault knowledge needs a bounded update. Consider three paths: source changes alone, source changes clarified by an investigation, and investigation evidence without a source change. Automatically absorb case-derived knowledge only after verifying its productive applicability. Independently supported source observations and corrections follow the evidence policy and remain distinct from deployed behavior.

For each relevant case claim, compare its evidence, scope and revision with the existing canonical note and any recorded destination. Reuse an already verified absorption; pursue only a new supported delta. A case-level status or a matching repository name does not settle an individual claim. Return verified destinations and evidence limits to the case owner through the responsible workflow.

## Offer the next useful action

When a concrete gap remains after the current task, state what is missing, why it matters, and the smallest next action. After a verified production deployment, offer to integrate eligible knowledge and map the affected scope. If repeated drift or missed follow-up is likely, offer a scheduled vault refresh and let the user choose its cadence and authorized effects. Do not turn unrelated answers or an unchanged scheduled run into recurring prompts.

## Follow through within authority

Once the user has authorized a scoped action, complete and verify it through the responsible skill. Suggesting a refresh does not authorize a schedule, a technical write, a source deployment, or a remote Git effect. A scheduled run uses its saved authorization and the applicable repository policy; unresolved evidence or conflicting contributions remain visible for review. Report what was incorporated, already covered, deferred or blocked without claiming that a case, deployment or sync receipt proves more than it does.

Answer clearly and concisely: lead with the result, explain unfamiliar terms, and retain evidence and limits that affect the decision.
